POTTER SERVICE HOSTING RECOMMENDATION

Recommended hosting: IONOS Web Hosting Plus.

For this project concept, Potter Service recommends considering the IONOS Web Hosting Plus plan. The reason is that the proposed service portal can be built around standard web hosting, PHP, subdomains, and MariaDB without requiring a separate database-hosting service. Final suitability should still be confirmed against the finished application's requirements before launch.

Why this plan fits the concept

STORAGE

Substantial web storage for the portal, website files, and related hosted projects.

DATABASES

250 MariaDB databases

IONOS lists 250 MariaDB databases at up to 2 GB each on the Plus plan. The portal itself would not be expected to require hundreds of databases; the important point is that database hosting is already included.

SUBDOMAINS

Recommended service subdomains

These are suggested production addresses. Replace yourdomain.com with the domain selected for the service.

admin.yourdomain.com

Admin Portal

Staff login, tickets, customers, devices, queue, requests, payments, search, and settings.

client.yourdomain.com

Client Portal

Customer-facing service portal and appropriate ticket information.

kiosk.yourdomain.com

Kiosk — only if selected

Dedicated in-store check-in/status interface if Mac PC Rescue chooses to add kiosk mode.

status.yourdomain.com

Simple Status — optional

A lightweight status-only site if the client prefers a simple service-request lookup using appropriate ticket/phone verification.

No other service subdomains should be necessary for the current concept.

Admin and Client are the main recommended addresses. Kiosk and Status are optional. Additional subdomains should only be created if the final project develops another clear functional need.
