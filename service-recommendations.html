POTTER SERVICE RECOMMENDATIONS

Keeping the Mac PC Rescue web services useful and low-cost.

These are Potter Service recommendations for services that could support the Mac PC Rescue website and related project while keeping recurring costs as low as practical. Mac PC Rescue can choose different providers at any time.

DOMAIN

Domain Registration

≈ $20 / year estimated

The domain can be purchased and kept with whichever domain registrar or hosting provider Mac PC Rescue prefers. The domain does not have to be purchased from the same company that hosts the website.

  • If the website moves to a different hosting provider, the domain can normally remain with its existing registrar.
  • The DNS records would simply need to be updated to point the domain to the new hosting provider.
  • Actual registration and renewal cost depends on the domain extension and registrar.
  • Premium domains can cost substantially more than a normal domain registration.
Domain Registrar→ DNS →Selected Web Host
WEB HOSTING

IONOS Web Hosting Plus

For the service-portal concept, Potter Service currently recommends considering IONOS Web Hosting Plus because the plan includes the standard web-hosting, PHP, subdomain, and MariaDB capabilities that fit the proposed project.

This is a recommendation rather than a requirement. Hosting can be changed later by moving the website/application files and databases and updating the domain's DNS.

DNS + SECURITY

Cloudflare Free

$0 / month for the Free plan

Potter Service recommends considering Cloudflare in front of the website. For the current project, the Free plan should cover many of the basic DNS, delivery, SSL, and DDoS-protection needs expected for the public website.

  • DNS management
  • CDN / content delivery features
  • Universal SSL availability
  • Unmetered DDoS protection on the Free plan
  • Additional security controls can be considered later if the project grows

Important: Cloudflare adds a useful security layer but does not make a website immune to every type of attack. Secure application code, updates, backups, access controls, and host security are still necessary.

TRAFFIC ANALYTICS

Google Analytics

$0 for the standard service

Potter Service recommends Google Analytics for understanding how visitors use the Mac PC Rescue website.

  • Website traffic and usage
  • Real-time activity reporting
  • Traffic sources and acquisition
  • Pages and events visitors interact with
  • Audience and demographic reporting where available and permitted

Analytics configuration should be reviewed for applicable privacy, consent, and data-collection requirements before deployment.

GOOGLE SEARCH

Google Search Console

$0 / free Google service

Search Console is recommended for monitoring and improving the website's presence in Google Search. It does not guarantee a particular search ranking, but it provides important tools for helping Google discover and understand the site.

  • Confirm that Google can find and crawl the website
  • Submit and monitor website indexing
  • Request re-indexing after important updates
  • See search queries and Google Search traffic
  • Identify indexing and other search-related problems

COST STRATEGY

Use free services where they make sense.

The general recommendation is to avoid paying for additional services unless the project actually needs them. A domain and web hosting may be the primary recurring costs, while Cloudflare, Google Analytics, and Google Search Console can initially provide useful supporting capabilities at no additional service cost.

If traffic, security requirements, storage, email, or application requirements grow later, paid services can be evaluated at that time instead of adding unnecessary overhead now.

LOW-COST APPROACH

Start with what the project actually needs.

A practical starting setup could consist of the selected domain, suitable web hosting, Cloudflare Free, Google Analytics, and Google Search Console. The domain remains portable between hosts, and additional paid services can be added later only when there is a clear need.

Domain→Cloudflare / DNS→Web Hosting+Google Analytics+Search Console
