PROJECT STRUCTURE

Designed to stay organized.

The hub uses a predictable folder layout so a placeholder can later be replaced by the real build without changing the central navigation.

Mac-PC-Rescue-Project-Hub/ ├── index.html ├── about.html ├── components.html ├── roadmap.html ├── structure.html ├── assets/ │ └── styles.css ├── website/ │ └── index.html ├── portal-concept/ │ └── index.html ├── admin/ │ └── index.html ├── client/ │ └── index.html └── kiosk/ └── index.html

Replacing a placeholder

When a project is ready, copy the complete build into its matching folder and keep its entry page named index.html. The Project Hub link will continue working.

Keep supporting files together

Remember to copy CSS, JavaScript, images, fonts, and any subfolders required by that individual build. A project may have its own assets separate from the Project Hub assets.
